# ג'ובנוער (JobNoar) — MVP

אתר סטטי (HTML/CSS/JS ללא בקאנד) לפרסום וחיפוש עבודות זמניות לבני נוער, בהשראת המסכים בתיקיית `Images`.

## מבנה הפרויקט

```
index.html            - עמוד חיפוש עבודה (רשימת משרות + סינון וחיפוש)
job.html               - עמוד פרטי משרה בודדת (?id=...)
apply.html             - טופס הגשת מועמדות (?id=...) - שולח הודעת WhatsApp למעסיק
faq.html               - שאלות נפוצות (בני נוער / מעסיקים)
css/style.css          - כל העיצוב של האתר
js/jobs.js             - "מסד הנתונים" של המשרות
js/main.js             - פונקציות עזר משותפות (וואטסאפ, ניווט מובייל וכו')
local-admin-tool/      - כלי מקומי לעריכת רשימת המשרות (⚠️ אסור להעלות ל-GitHub, ראו למטה)
```

**חשוב:** התיקייה `local-admin-tool/` אינה חלק מהאתר. היא כלי אישי שרץ רק במחשב שלכם, ומטרתה להפיק קובץ `jobs.js` מעודכן. הקבצים שכן מעלים ל-GitHub (כלומר לאתר החי) הם: `index.html`, `job.html`, `apply.html`, `faq.html`, `css/`, `js/`, ו-`README.md` בלבד. קובץ ה-`.gitignore` בפרויקט כבר מוגדר למנוע העלאה בטעות של `local-admin-tool/` אם תעבדו עם Git.

## איך זה עובד (MVP ללא שרת)

- **אין בקאנד ואין מסד נתונים.** כל המשרות מוגדרות כמערך JavaScript בקובץ [`js/jobs.js`](js/jobs.js).
- **הגשת מועמדות** בונה הודעת WhatsApp מוכנה עם כל פרטי המועמד/ת, ופותחת שיחה ישירות עם מספר הוואטסאפ שהוגדר למשרה (`whatsapp` באובייקט המשרה). אין שמירה של נתוני מועמדים בשום מקום - זו הגשה חד-פעמית שמועברת ישירות למעסיק.
- **פרסום משרה** הוא כרגע **במצב פיתוח בלבד**: את/ה (המפתח/ת) מוסיפ/ה משרות חדשות ישירות בקובץ `js/jobs.js`. בעתיד אפשר להחליף את זה בטופס/מסד נתונים אמיתי לפרסום עצמאי ע"י מעסיקים.

## איך מוסיפים / עורכים / מוחקים משרה (מצב פיתוח)

### דרך מומלצת: כלי הניהול המקומי (בלי לגעת בקוד)

1. פתחו את [`local-admin-tool/index.html`](local-admin-tool/index.html) על ידי לחיצה כפולה עליו (הוא נפתח בדפדפן, לא צריך שרת).
2. אם כבר יש לכם קובץ `jobs.js` עדכני (למשל כזה שהורדתם בפעם הקודמת) - לחצו "ייבוא קובץ jobs.js קיים" כדי לטעון אותו. אחרת, הכלי ייטען עם המשרות לדוגמה שכבר קיימות בפרויקט.
3. הוסיפו משרה חדשה עם "+ הוספת משרה חדשה", ערכו משרה קיימת עם "✏️ עריכה", או מחקו עם "🗑️ מחיקה". כל שינוי נשמר אוטומטית בדפדפן (טיוטה מקומית) כך שאם תסגרו את הדף בטעות, העבודה לא תאבד.
4. גם כאן מוגדר מספר הוואטסאפ הכללי לתמיכה (בראש העמוד) - הכלי ידאג להזין אותו בפורמט הנכון בכל האתר.
5. בסיום, לחצו "⬇️ הורדת קובץ jobs.js מעודכן" - יורד קובץ `jobs.js` חדש למחשב שלכם.
6. העלו את הקובץ הזה ל-GitHub במקום הישן: בריפו שלכם היכנסו לקובץ `js/jobs.js`, לחצו על עיפרון העריכה (או "Upload files" כדי להחליף אותו), הדביקו/העלו את התוכן החדש, ו-Commit. תוך דקה השינוי יהיה חי באתר.

**⚠️ שימו לב:** לעולם אל תעלו את התיקייה `local-admin-tool/` עצמה ל-GitHub - היא כלי עבודה אישי בלבד ולא אמורה להיות נגישה לגולשי האתר.

### דרך חלופית: עריכה ידנית של הקובץ

1. פתחו את [`js/jobs.js`](js/jobs.js).
2. העתיקו אובייקט משרה קיים בתוך מערך `JOBS` והדביקו אותו בסוף המערך (לפני `]`).
3. עדכנו את השדות:
   - `id` — מזהה ייחודי באנגלית בלי רווחים, למשל `"cashier-yohananof"`.
   - `title`, `business`, `businessType`, `city`, `address` — טקסט בעברית.
   - `icon` — אימוג'י שמייצג את סוג העבודה (מוצג כתמונת "תמונה ממוזערת").
   - `tileColor` — קוד צבע (hex) לרקע האייקון, לדוגמה `"#f6e2b8"`.
   - `hoursFrom`, `hoursTo` — שעות עבודה, פורמט `"HH:MM"`.
   - `salary` — שכר לשעה במספר (ש"ח).
   - `minAge` — גיל מינימלי (מספר).
   - `deadline` — תאריך אחרון להגשה, פורמט `"DD.MM.YYYY"`.
   - `badges` — מערך תגיות אופציונלי, כל תגית: `{ text: "פופולרי", type: "pink", icon: "🔥" }`. `type` יכול להיות `green` / `pink` / `blue` / `amber`.
   - `description`, `note`, `businessDetails` — טקסטים חופשיים.
   - `whatsapp` — **חשוב!** מספר הוואטסאפ האמיתי של המעסיק, בפורמט בינלאומי בלי `+` ובלי `0` מוביל. לדוגמה `050-1234567` → `"972501234567"`.
   - `tags` — מערך תחומי עניין (לשימוש עתידי בהתאמות).
4. שמרו את הקובץ ורעננו את הדפדפן - המשרה תופיע מיד ברשימה.

כדי להוריד משרה מהאתר - פשוט מחקו את האובייקט שלה מהמערך.

## עדכון מספר הוואטסאפ הכללי של האתר

בראש הקובץ `js/jobs.js` יש קבוע:

```js
const SITE_WHATSAPP = "972500000000";
```

זהו המספר שמוצג בכפתור הוואטסאפ הצף בכל עמודי האתר, ובקישורי "צ'אט בוואטסאפ" בתפריט ובפוטר בכל העמודים - כולם נשלפים אוטומטית מהקבוע הזה (`js/main.js`), כך שמספיק לעדכן אותו במקום אחד בלבד (או דרך כלי הניהול המקומי).

## הרצה מקומית

אין צורך בהתקנות. פשוט פתחו את `index.html` בדפדפן, או הריצו שרת סטטי פשוט (מומלץ, כדי למנוע בעיות CORS עתידיות אם יתווספו קבצי JSON חיצוניים):

```bash
npx serve .
```

## פרסום ל-GitHub Pages

⚠️ **אל תעלו את תיקיית `local-admin-tool/`** - היא לא חלק מהאתר. אם אתם מעלים קבצים ידנית דרך אתר GitHub (גרירה), פשוט אל תגררו את התיקייה הזו. אם אתם עובדים עם Git, קובץ ה-`.gitignore` כבר דואג לכך אוטומטית.

1. צרו repository חדש ב-GitHub והעלו אליו את כל תיקיית הפרויקט (חוץ מ-`local-admin-tool/`):
   ```bash
   git init
   git add .
   git commit -m "JobNoar MVP"
   git branch -M main
   git remote add origin https://github.com/<username>/<repo-name>.git
   git push -u origin main
   ```
2. בהגדרות ה-repository ב-GitHub: **Settings → Pages**.
3. תחת **Source** בחרו `Deploy from a branch`, ענף `main`, תיקייה `/ (root)`.
4. שמרו - האתר יהיה זמין תוך דקה-שתיים בכתובת `https://<username>.github.io/<repo-name>/`.

## מה עוד חסר לגרסה מלאה (מעבר ל-MVP)

- הרשמה/התחברות אמיתית לבני נוער ולמעסיקים.
- טופס עצמאי למעסיקים לפרסום משרות (במקום עריכת `jobs.js` ידנית).
- שמירת "משרות שמורות" ופרופיל אישי (כרגע אין התחברות אז אין שמירה).
- מסד נתונים אמיתי (Firebase / Supabase וכו') במקום קובץ JS סטטי.
- שיתוף משרה (WhatsApp / Instagram / SMS / קישור) בדף המשרה.
